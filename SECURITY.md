# Sécurité

N’envoyez pas de détails d’une vulnérabilité exploitable dans une issue publique. Utilisez le canal **Report a vulnerability** de GitHub Security Advisories pour ce dépôt lorsqu’il sera publié. Incluez la version affectée, un scénario de reproduction réduit et l’impact observé.

Rappel : Orbit n’isole pas le code JavaScript des plugins. N’exécutez pas un plugin non fiable dans le même processus que des secrets ou des données sensibles.
