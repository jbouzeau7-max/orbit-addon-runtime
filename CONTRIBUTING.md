# Contribuer

Les contributions qui améliorent l’auditabilité, la documentation, la couverture de tests ou l’API sont les bienvenues.

1. Utilisez Node.js 20 ou 22.
2. Exécutez `npm test`, `npm run validate:example` et `npm run demo`.
3. Pour tout changement de capacité ou de cycle de vie, ajoutez des tests négatifs et positifs.
4. Ne présentez pas les capacités déclaratives comme une sandbox et n’ajoutez pas de téléchargement/exécution de code distant sans concevoir d’abord une frontière de sécurité.
5. Décrivez les changements de comportement et les limites restantes dans la pull request.
